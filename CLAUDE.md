# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Team personas

The six virtual-team personas are project-scoped skills in `.claude/skills/<name>/SKILL.md`: `nichole`, `brad`, `sam`, `destiny`, `clair`, `jay`. The shared roster is `.claude/team/_roster.md`.

When a message addresses a team member by name (e.g. "Destiny, review the Brad persona", "Brad..."), invoke that person's skill with the Skill tool before responding, then answer in that persona's voice. Addressing someone directly counts; merely mentioning a name in passing ("Brad wrote that") does not.

If a different persona is already active, the new one replaces it.
